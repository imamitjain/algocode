# AlgoCode

Quick-reference site for DSA and language idioms across Java, Go, C++, and Python.

**Live site:** https://imamitjain.github.io/algocode/

## What's Covered

- **Java** — 150 cards across 22 categories covering collections, data structures, sorting, searching, linked list/tree/graph templates, Dijkstra, Bellman-Ford, Floyd-Warshall, Kruskal's MST, monotonic stack, segment tree, Fenwick tree, sieve, modular inverse, nCr mod p, algorithm patterns, interface hierarchy, time complexity tables, String/Array operations, concurrency, and algorithm mental models.
- **Golang** — 89 cards across 23 categories covering idiomatic Go patterns, data structure tricks, trie, union-find, Bellman-Ford, Floyd-Warshall, Kruskal's MST, monotonic stack, segment tree, Fenwick tree, sieve, modular inverse, nCr mod p, algorithmic techniques, two pointers, prefix sum, topological sort, interval patterns, edge cases, pitfalls, and algorithm mental models.
- **C++** — 85 cards across 16 categories covering STL containers, math utilities, bit manipulation, sorting, searching, trie, union-find, Bellman-Ford, Floyd-Warshall, Kruskal's MST, monotonic stack, segment tree, Fenwick tree, sieve, modular inverse, nCr mod p, two pointers, prefix sum, topological sort, interval patterns, algorithm patterns, and algorithm mental models.
- **Python3** — 80 cards across 18 categories covering built-in data structures, trie, union-find, Bellman-Ford, Floyd-Warshall, Kruskal's MST, monotonic stack, segment tree, Fenwick tree, sieve, modular inverse, math.comb, nCr mod p, two pointers, prefix sum, topological sort, interval patterns, sorting, searching, Pythonic idioms, itertools/functools, and algorithm mental models.
